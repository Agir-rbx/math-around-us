# Математика вокруг нас

Проектная работа по информатике.

Тема: **Математика вокруг нас от природы до современных технологий**.

Сайт: https://Agir-rbx.github.io/math-around-us/

Две вкладки: приветствие и видеоплеер. Видео проекта и русские субтитры доступны всем посетителям; выбирать файл на своём устройстве не требуется. Озвучка начинается на 12,52 секунде, вместе с презентацией.

Плеер поддерживает громкость, перемотку, скорость 0,25–2×, субтитры и их оформление, полноэкранный режим и светлую/тёмную тему. Можно выбрать другое локальное видео и загрузить VTT/SRT для текущего просмотра, затем вернуть видео проекта.

Управление: пробел/K — воспроизведение и пауза; ←/→ — ±5 секунд; J/L — ±10 секунд; M — звук; C — субтитры; F — полный экран; T — режим кинотеатра.

## Файлы

- `index.html`, `style.css`, `script.js` — сайт без внешних библиотек.
- `assets/video/*.part` — части видео H.264/AAC, 910×512, около 1:12. Плеер автоматически собирает их в один ролик.
- `assets/subtitles-ru.vtt` — субтитры с таймингом озвучки.
- `assets/poster.jpg` — кадр из видео.
- `.nojekyll` — отключение обработки Jekyll.

Для GitHub Pages: ветка `main`, папка `/(root)`. Для просмотра локальной копии запусти в папке `python3 -m http.server 8000` и открой http://localhost:8000/.
